# ✍️ Text to Handwriting Studio

A desktop application for creating handwriting-style documents using **Python** and **PySide6**.

Text to Handwriting Studio provides a visual workspace where you can enter or paste text, apply handwriting-style fonts, customize its appearance, arrange content on a virtual page, and export the finished document.

## ✨ Features

### ✍️ Text to Handwriting

- Enter or paste text
- Choose from installed fonts
- Adjust font size
- Change ink colour
- Create multi-line documents

### 📄 Paper Styles

The application includes several paper backgrounds:

- Warm White
- Pure White
- Cream
- Yellow Legal Paper
- Graph Paper
- Ruled Paper

### 🖼 Visual Canvas

The interactive canvas allows you to:

- Add handwriting-style text
- Add images
- Drag items around the page
- Select elements
- Rotate items
- Change opacity
- Bring items forward
- Send items backward
- Delete selected items

### 🔍 View Controls

- Zoom in
- Zoom out
- Fit page to window

### 💾 Project Support

- Create new projects
- Save projects
- Open saved projects

### 📤 Export

Export completed documents as:

- PNG
- PDF

## 🖥️ Technology

- Python
- PySide6
- Qt Graphics View Framework
